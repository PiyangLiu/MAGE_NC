# Figure 6 liquid-liquid topology

`run_figure6_lle.py` constructs two stable branches of the analytic regular-Helmholtz liquid-liquid model. Only compositions outside the spinodal interval are eligible as tangent-plane supports. Candidate, validation, and test pools are independent, and coexistence is compared with the analytic common-tangent result.

Use `--quick` for a smoke test. The retained convergence and coexistence data are in `../../data/gerg_lle_plot_data.json` and the machine-readable source tables are under `../../source_data/Figure5`.
